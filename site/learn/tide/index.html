Learn / TIDE

A test token with public rules.

TIDE is the token used in the TikiDeco prototype. It helps test how eligibility rules and public records can be inspected on Ethereum Sepolia.

undefined

Three things to understand

Sepolia
A public Ethereum testing network. The current TikiDeco contracts run here.
A balance
A record of test tokens at an address. The website can read that record without connecting your wallet.
Eligibility
A comparison against test campaign rules. A matching balance does not confirm access, a reservation or a real-world benefit.

Follow the demonstration

1. Open the checker
Enter a public test wallet address on the pilot page.
2. Read the result
The checker requests Sepolia data and explains its result. If data cannot be obtained, it shows an unavailable state.
3. Review the rules
The campaign remains draft-not-live. Explore the operator sandbox to see a fictional review workflow.

Versions and limitations

V1
The canonical legacy Sepolia deployment. Contract addresses are available in the verification center.
V2
A non-canonical candidate for community review. Community review is not a formal independent audit.
Current boundary
No sale; no stated monetary value; no mainnet deployment; no active guest benefits; not independently audited.
