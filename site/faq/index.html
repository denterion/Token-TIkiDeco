About the project

Is TikiDeco a hotel?
There is no commercial hospitality service operating. The project explores future loyalty and access workflows.
What can I do today?
Read the project facts, check a public Sepolia test address and explore the operator demonstration with fictional data.
Why use a public network?
It allows reviewers to inspect selected rules and records independently. It does not prove that an off-chain service or benefit exists.

Using the demonstration

Do I need to connect a wallet?
No. Browsing requires no wallet. The balance checker accepts a manually entered public address.
What does a matching balance mean?
It satisfies a test balance threshold only. The campaign is draft-not-live and no guest benefit is activated.
What information should I enter?
Only a public test address in the checker. Never enter private keys, recovery phrases or guest information. RPC providers receive the public address being queried.
Why is the result unavailable?
The public RPC service may be unreachable or return an unexpected network. Try again later; unavailable data is not a zero balance.

Status and participation

Is TIDE offered for sale?
No sale. TIDE has no stated monetary value and no mainnet deployment.
Has there been an independent audit?
Independent audit not started. Internal checks and community peer review do not establish an independent audit.
How can I help?
Test the demonstrations, suggest clearer wording or review the public code. Report sensitive vulnerabilities through the private reporting route.
